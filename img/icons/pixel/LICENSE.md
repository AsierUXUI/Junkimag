# Pixel icons

**Pixel free icons** by [Streamline](https://www.streamlinehq.com/icons/pixel)
([source](https://github.com/webalys-hq/streamline-vectors)), licensed under
[Creative Commons Attribution 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

- 662 icons, 32×32, one colour (`fill="currentColor"`), so they take the colour of
  the surrounding text or of a CSS `color`.
- Converted to individual SVG files from the official Iconify package
  `@iconify-json/streamline-pixel` 1.2.0. The artwork is unchanged.
- `index.json` lists every icon name. Browse them all at `icons.html` in the site root.

CC BY 4.0 requires credit: when an icon is used on the site, keep a line like
"Icons: Pixel by Streamline (CC BY 4.0)" somewhere on the site (e.g. the footer or About page).
